faulthandler all-thread stack dump, taken while the TUI was frozen
=================================================================
How: launched the real TUI under a pseudo-tty with `faulthandler.dump_traceback_later(...)`
armed, opened + dismissed the trade dialog, then let the dump fire while frozen.

Reading: this is NOT a CPU spin. The asyncio loop (main thread) is parked idle in
selectors.select, and the driver's input thread is alive and blocked reading the tty. Input
is being read at the OS level but never dispatched into the app, because the loop is wedged
in the never-finishing screen teardown (see asyncio-task-dump.txt). That is why the screen
looks normal (dialog gone, board intact) yet no keystroke — including Ctrl-C — does anything.
